# 🎓 Student Management System

A simple **Student Management System built using Python**.
This project is designed for beginners to practice **Python basics, dictionaries, loops, conditional statements, and user input**.

## 🚀 Features

* ➕ Add a new student
* ❌ Delete a student
* ✏️ Update student marks
* 🔍 Search for a student
* 📋 Display all students
* 📊 Calculate average marks
* 🚪 Exit the program
* 🖥️ Simple menu-driven interface

## 🛠️ Technologies Used

* **Python 3**
* Dictionaries
* Loops
* Conditional Statements
* User Input
* Functions/Basic Python Concepts

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd Student-Management-System
```

### 3. Run the Python program

```bash
python student_management.py
```
